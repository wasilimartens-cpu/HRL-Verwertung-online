# Verwertung-Tool online (Version 32)

Gemeinsames Erfassungs-Tool für die Verwertung: mehrere Mitarbeiter, ein Datenstand,
Druck-Eingang im Büro für Belege, die vom Handy gesendet werden.

- Start: `npm start` (Node.js ab 22.13, keine weiteren Pakete nötig)
- Passwort: Umgebungsvariable `APP_PASSWORT`
- Daten: SQLite-Datei im Ordner `DATA_DIR` bzw. im Railway-Volume

Ausführliche Schritt-für-Schritt-Anleitung: **[Anleitung.md](Anleitung.md)**
